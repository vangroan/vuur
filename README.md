
# Vuur

Vuur is a little hobby scripting language, and is not intended for serious production use.

## Goals

This project is an academic playground for me to learn scripting implementation.
Features will be kept to a limited set well trodden by prior art.

1. Dynamic (runtime) typed values.
2. Closures as values.
3. Fibres (green threads, coroutines)
